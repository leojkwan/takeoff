## Conduct

Cadence prior: deliberate before an authorized installed-runtime change,
30-minute L0-L2 budget. There is no standing Takeoff scheduler. The product's
08:00/20:00 LaunchAgent is field behavior, not Takeoff automation.

Landing mode: direct push to `main` after declared proof, per ai-leo's repository
instructions. Source rollback is `git revert <landed-sha> && git push origin
HEAD:main`. Installed rollback uses the exact backup path and
`backup_manifest_sha256` from the sole terminal install receipt. Neither path
loads, unloads, kickstarts, retries, drafts, sends, or accesses a provider.

Ordinary passes may run `assistant-digest.sh` only with `--check`, and only
through the disposable ownership suite. Live installation, authorization-file
creation, `launchctl` mutations, manual producer execution, provider actions,
and natural-window inspection are outside the pass unless the owning Shadow row
contains that exact authorization.

## Mutation rotation

Run two distinct classes per pass. Each mutation requires the planted diff, the
named RED guard, restoration to zero diff, and the same guard GREEN:

1. Compact `-0400` timestamp rejection; marker-preserving raw-HTML mutation.
   Guards: `test_preflight_accepts_macos_date_compact_timezone_offset` and
   `test_native_readback_rejects_marker_preserving_html_mutation`.
2. Plaintext / `<pre>` rendering; false all-clear with incomplete identity
   coverage. Guards: `test_prepare_renders_the_actual_html_payload_and_separate_opportunity`
   and `test_all_clear_requires_complete_expected_account_coverage`.
3. Dropped unresolved follow-up; draft/send retry after ambiguity. Guards:
   `test_prior_unresolved_mail_obligation_cannot_disappear` and
   `test_ambiguous_draft_creation_fails_closed_without_send_retry`.
4. Missing or corrupt installed component; mismatched rollback transaction.
   Guards: `test_corrupt_backup_refuses_before_changing_any_installed_component`,
   `test_rollback_refuses_post_install_drift_before_restoring_any_component`,
   and `test_rollback_requires_exact_digest_and_archived_manifest`.

## Known boundary

L3 is intentionally `none`. A future rendered 900 px / 390 px visual receipt is
a separate improvement; its absence does not turn mocked or structural HTML
tests into field proof. L4b remains owned by Shadow's natural-window checkpoint
and must report one exact wake when any account or provider predicate is absent.
