Python 3.10+, Git, and an agent that can run local commands. Takeoff itself is a prompt and a few scripts.

Open a clean checkout of your project, then ask Claude Code or Codex to set up Takeoff and run a bounded local release review.

Ask your agent:

Set up Takeoff and review this repository for release. If Takeoff is not
available, clone https://github.com/leojkwan/takeoff.git into a temporary sibling
checkout and use its review instructions. Run the relevant checks, challenge weak
tests with reversible local changes, and leave an honest receipt. Do not push,
deploy, publish, or change account settings.

Terminal-driven Codex is also supported:

cd /path/to/your-project
codex exec --cd "$PWD" "$(takeoff prompt)"

A report you can question.

The local receipt names the commit checked, commands run, defects found, and anything the agent could not exercise. Review it before approving a release. If you choose to stamp it, Takeoff saves a durable local copy and an ADOPTION ledger row; neither is approval or independent verification.
